# Brand Voice — 톡캐치 (TokCatch)

> Vibe UX · brand-voice 산출물
> 작성일: 2026-06-12
> 기반: docs/idea.md, docs/benchmark.md, docs/userflow.md

## 확정 정보
- **서비스 이름:** 톡캐치 (TokCatch)
- **한 줄 무드:** 화자로 나서지 않는 도구 — 주인공은 PM 본인이고, 톡캐치는 배경에서 조용히, 간결하되 따뜻하게 아이디어를 제자리에 놓아준다.

> **표기 메모:** 영문 `TokCatch`는 App Store에 동일 철자의 틱톡 영상 앱이 있어, 글로벌·도메인 확장 시 표기를 다듬을 여지가 있다(한국 타깃 우선이라 당장은 그대로 사용).

---

## 1. Voice Summary

Sounds like **PM의 작업 맥락을 이미 꿰고 있는 조용한 도구** who 던지면 군말 없이 제자리에 놓아주고, 필요한 순간에만 담담히 다시 꺼내 보여준다.

톡캐치는 자기를 화자로 내세우지 않는다. "제가 분류했어요"라고 생색내는 AI도, 친근하게 수다 거는 팀원도 아니다. 주인공은 이 앱을 쓰는 PM이고, 톡캐치는 그 PM을 잘 이해해서 흩어지지 않게 받아주는 배경의 도구다. 그래서 말은 짧고, 끼어들지 않으며, 짧은 한마디에도 온기가 있다.

## 2. Core Personality Traits

**간결한 (Concise)**
- We are: 한 호흡에 끝나는 짧은 문장. 묻는 것 하나, 알려주는 것 하나. 군더더기 없이 핵심만.
- We are not: "저장됨." 같은 무미건조한 시스템 로그. 간결함이 차가움이 되어선 안 된다.
- This sounds like: "B프로젝트에 담았어요."
- This does NOT sound like: "메모 1건 저장 완료. (ID: 0192)"

**빠른 (Fast)**
- We are: 던지는 순간 1초에 끝나는 흐름. 결정에 필요한 것만 즉시 내밀고 비켜선다.
- We are not: 사용자를 재촉하는 톤. 빠름은 "내가 빨리 끝내준다"는 것이지 "너 빨리 해라"가 아니다.
- This sounds like: "어디로 갈까요?" (후보를 나란히 펼치고 1탭으로 끝)
- This does NOT sound like: "아직 분류 안 했어요! 어서 정하세요 👀"

**믿음직한 (Dependable)**
- We are: 추천이 척척 맞아 안심되는, 던진 게 사라지지 않고 제때 다시 떠오르게 해주는.
- We are not: 똑똑한 척 생색내거나 "AI가 분석했다"며 자기를 앞세우는.
- This sounds like: "3일 전 'B프로젝트 온보딩 개선' 적어두셨어요."
- This does NOT sound like: "AI가 분석한 결과, 최적의 프로젝트를 찾았습니다!"

## 3. Tone Spectrums

```
Formal     [1]——[2]——[●3]——[4]——[5]  Casual
Serious    [1]——[2]——[3]——[●4]——[5]  Playful
Authority  [1]——[2]——[3]——[4]——[●5]  Peer-level
Technical  [1]——[2]——[3]——[●4]——[5]  Simple
Reserved   [1]——[2]——[●3]——[4]——[5]  Enthusiastic
Bold       [1]——[2]——[3]——[●4]——[5]  Subtle
```

- **Formal–Casual (3):** 존댓말 기본의 편안한 중립. 딱딱하지도, 반말로 친한 척하지도 않는다.
- **Serious–Playful (4):** 담담하되 온기 있는 쪽. 다만 호들갑·감탄사로 가지 않는 절제된 가벼움.
- **Authority–Peer (5):** 가르치지 않는다. 주인공은 PM, 톡캐치는 결정을 대신하지 않고 곁에서 받쳐주는 도구.
- **Technical–Simple (4):** 평이한 말. 단, PM이 익숙한 도구라 과한 설명충은 불필요 — 간결한 쉬움.
- **Reserved–Enthusiastic (3):** 차분한 중립. 기뻐도 조용히, "🎉 축하해요!!"로 터지지 않는다.
- **Bold–Subtle (4):** 은은하게 비켜서는 쪽. 화자로 나서지 않는 무드의 직접적 반영.

## 4. Vocabulary Guide

**USE** — 톡캐치를 체현하는 표현

| 표현 | 언제 / 왜 |
|------|-----------|
| 툭, 던지다 | 캡처의 가벼움을 상징하는 핵심 동사. "툭 던지세요" |
| 담았어요 / 담을까요 | 분류 완료·제안. 깔끔한 완결형 |
| 어디로 갈까요 | 매칭 추천. 결정을 사용자에게 넘기는 톤 |
| 적어두셨어요 | 리마인더. 사용자가 한 행동을 그대로 되살림 |
| 정리는 알아서 | 핵심 가치 한 줄. 가벼움과 신뢰를 동시에 |
| 제자리 | "흩어지지 않는다"는 신뢰의 은유 |
| 한눈에 | 모아보기의 가치 |
| 다음에 봐도 괜찮아요 | 리마인더의 여유 — 재촉하지 않음 |
| 모여 있어요 | 흩어진 줄 알았던 게 정돈돼 있다는 안도 |
| 방금 / 3일 전 | 구체적이고 담담한 시간 표기 |

**AVOID** — 톡캐치와 어긋나는 표현

| 표현 | 왜 금지 |
|------|---------|
| 우와! / 멋져요!! / 대박 | 호들갑·감탄사. 담백함과 정면충돌 |
| 어서 / 얼른 / 지금 당장 | 재촉. "다음에 해도 괜찮다"는 여유와 반대 |
| AI가 분석했어요 / 제가 골랐어요 | 톡캐치가 화자로 나서는 톤. 주인공은 PM |
| 까먹기 전에 / 놓치지 마세요 | 불안·압박을 자극 |
| 연속기록 / 갓생 / 폭발 / 1000% | 동기부여 코치 톤. 톡캐치가 의도적으로 비켜가는 자리 |
| 저장 완료 / 처리되었습니다 | 무미건조한 시스템 로그 톤 |
| seamless / ideation / sync (영어 남발) | PM이 거슬려 할 전문용어 떡칠 |
| 혁신하세요 / 생산성을 높이세요 | 과장된 마케팅 호들갑 |
| 🎉🔥💸👀 (자극성 이모지) | 축하·압박을 과장. 이모지는 절제 |
| 당신을 기다리고 있어요(알림에서) | 의인화로 톡캐치를 화자화 |

## 5. Tone Adaptation Rules

보이스 속성(간결·빠름·믿음직, 그리고 "화자로 나서지 않음")은 어느 맥락에서도 고정. 맥락에 따라 **따뜻함과 담담함의 균형만** 조절한다.

**By Context (앱 안 맥락):**

| 맥락 | 톤 조절 | 예시 문구 |
|------|---------|-----------|
| 온보딩 / 첫 화면 | 가치를 한 줄로, 담담하게 권유 | "떠오르면 툭, 정리는 알아서." |
| 빈 상태(empty state) | 부담 없이 첫 행동을 부드럽게 안내 | "아직 비어 있어요. 떠오르는 걸 툭 던져보세요." |
| 성공/완료 피드백 | 간결하되 온기를 한 스푼 (★공들이는 자리) | "B프로젝트에 담았어요." / "팀 보드에 올렸어요." |
| AI 매칭 추천 | 후보를 나란히, 결정은 사용자에게 (★가장 공들이는 자리) | "어디로 갈까요? · 결제개편 · 온보딩리뉴얼 · 검색고도화" |
| 에러 / 안내 | bold를 낮추고 차분하게, 책임을 사용자에게 떠넘기지 않음 | "잠깐 안 담겼어요. 다시 던져볼까요?" |
| 리마인더 / 푸시 | 최소한으로, 적어둔 내용을 그대로 되살림 (재촉 금지) | "3일 전 'B프로젝트 온보딩 개선' 적어두셨어요." |
| 랜딩 / 소개 페이지 | 가벼움과 신뢰를 한 호흡에, 과장 없이 | "던질 땐 메모앱처럼 가볍게, 쌓이면 노션처럼 정리되게." |

규칙: **성공 피드백**에선 따뜻함을 키우고, **에러 안내**에선 bold를 1로 낮추고 차분함을 올린다. **푸시**는 빈도 자체를 최소화하고 톤은 늘 담담하게. 어느 맥락에서도 톡캐치가 "내가 했다"고 나서지 않는다.

## 6. Style Rules

- **존댓말 기본** — `~해요` / `~어요`. 반말로 친한 척하지 않음.
- **문장은 한 호흡** — 짧고 명료하게. 한 화면에 묻는 것 하나, 알려주는 것 하나.
- **이모지 절제** — 분류·완료 확인 자리에 최대 1개(`✓`). 알림·리마인더엔 쓰지 않음. 자극성 이모지(🔥💸👀) 금지.
- **느낌표 최대 1개, 거의 안 씀** — 담담함이 기본. 감탄부호로 띄우지 않는다.
- **시간은 구체적으로** — "방금", "3일 전"처럼 사람이 읽는 표기.
- **사용자 행동을 그대로 되살림** — 리마인더엔 적어둔 키워드를 그대로 인용.
- **외래어보다 평이한 한글** — PM 대상이어도 전문용어 떡칠은 피한다.

## 7. Do's and Don'ts

**Do:**
- 던진 직후 어디 들어갔는지 짧게, 따뜻하게 확인해준다. ("B프로젝트에 담았어요.")
- AI 매칭은 후보를 나란히 펼치고 마지막 선택은 사용자에게 넘긴다.
- 리마인더는 적어둔 내용을 그대로 되살려 "아 맞다, 이거"가 떠오르게 한다.
- 짧게 쓴다 — 한 문장으로 될 일을 두 문장으로 늘리지 않는다.
- 온기는 단어 하나, 어미 하나로 — 호들갑 없이.
- 에러는 사용자 탓으로 돌리지 않고 차분히 다음 행동을 제시한다.

**Don't:**
- "제가 분류했어요 / AI가 골랐어요"처럼 톡캐치를 화자로 내세우지 않는다.
- "얼른 / 까먹기 전에 / 지금 당장"으로 재촉하거나 불안을 자극하지 않는다.
- 감탄사·호들갑·자극성 이모지로 분위기를 띄우지 않는다.
- "저장 완료 / 처리되었습니다" 같은 시스템 로그 톤으로 차갑게 굴지 않는다.
- 동기부여 코치처럼 "연속기록 / 갓생"으로 몰아붙이지 않는다.
- 푸시 알림을 남발하지 않는다 — 꼭 필요할 때만, 조용히.
