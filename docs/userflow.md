## 플로우 1 · 던지기 — "방금 떠올랐어, 일단 던져야지"  [메인 기능: 즉시 캡처 · AI 매칭]

**목표 순간:** 이동 중·자기 전 갑자기 아이디어가 떠오름 → 키워드만 툭 던졌더니 그 자리에서 프로젝트로 묶여 **머릿속 키워드가 첫 프로젝트로 정리됨** (상태 변화: 흩어진 생각 → 분류된 첫 아이디어 / 빈손 → 첫 결과물)

> **설계 노트:** 첫 사용이라 프로젝트가 0개 → ③에서 케이스 B(즉석 등록) 경로를 밟는다. AI 추천 칩으로 1초 선택하는 케이스 A는 같은 ③ 화면이 프로젝트가 쌓이면 자동으로 동작하는 모드이며, 본격 시연은 두 번째 던지기부터 이어진다. 플로우 1은 "첫 던지기 한 바퀴"에서 닫는다.

**단계 시퀀스**

| 단계 | 화면 | 기능 | 주 행동 (→ 전진) | 보조 |
|:--:|------|------|------------------|------|
| ① | 환영 화면 | 진입 | [바로 시작하기] → ② | 로그인 없이 시작 |
| ② | 캡처 화면 | 즉시 캡처 | 키워드 입력 → [던지기] → ③ | (음성·첨부 P1) |
| ③ | AI 매칭 & 분류 | AI 매칭 / 프로젝트 등록 | 프로젝트로 담기 → ④ | 분류 없이 저장 |
| ④ | 홈 (결과 확인) | 프로젝트별 확인 | (종료) 또 던지려면 → ② | + 아이디어 던지기 |

**화면**

### ① 환영 화면
```
 ┌─────────────────────────┐
 │                         │
 │      💭 → 📁            │
 │                         │
 │   떠오르면 툭,           │
 │   정리는 알아서.         │
 │                         │
 │   키워드만 던지면        │
 │   AI가 프로젝트로        │
 │   정리해드려요.          │
 │                         │
 │   [  바로 시작하기  ]    │
 │                         │
 │   로그인 없이 시작       │
 └─────────────────────────┘
```
- **역할:** 톡캐치의 가치("던질 땐 가볍게, 정리는 알아서")를 한눈에 전하고 마찰 없이 진입시킴
- **담는 정보·요소:** 던지기→정리 시각 한 컷 · 가치 한 줄 · [바로 시작하기]
- **주 행동:** [바로 시작하기] → ②  *(게스트로 시작. 로그인은 공유·동기화가 필요한 순간(플로우 2)에 유도 — v1 결정)*

### ② 캡처 화면 (열자마자 커서)
```
 ┌─────────────────────────┐
 │  ✕                      │   ← 닫으면 홈
 │   ┃                     │   ← 커서 깜빡, 키보드 바로 올라옴
 │   여기에 툭 던지세요     │   (placeholder)
 │                         │
 │                         │
 │─────────────────────────│
 │  🎤(P1)     [ 던지기 → ]│
 │═════════════════════════│
 │       (키보드)          │
 └─────────────────────────┘
```
- **역할:** "1초에 던진다"의 심장. 머릿속 키워드를 옮기는 행동 하나에만 집중시킴
- **담는 정보·요소:** 입력창(자동 포커스) · [던지기] · (🎤 음성은 P1)
- **주 행동:** 텍스트 입력 → [던지기] → ③  (전진 조건: 내용이 한 글자라도 있을 것)
- *던지는 순간엔 프로젝트·태그·날짜를 일절 묻지 않는다 — 그건 ③에서 AI가 대신한다.*

### ③ AI 매칭 & 분류
방금 던진 문장을 위에 고정하고, 같은 화면 아래로 추천이 펼쳐진다(화면 전환 없음 — 맥락 유지).

**케이스 B — 프로젝트가 하나도 없을 때 (첫 사용, 플로우 1의 실제 경로)**
```
 ┌─────────────────────────┐
 │  ✕                      │
 │  "로그인 화면 A/B 테스트 │  ← 방금 던진 내용 (상단 고정)
 │   해보면 어떨까"         │
 │─────────────────────────│
 │  담을 프로젝트가 아직    │
 │  없네요. 새로 만들까요?  │
 │                         │
 │  프로젝트 이름           │
 │  [____________________] │  ← 직접 입력 (자동 포커스)
 │                         │
 │  [  만들고 담기 ]       │
 │  [ 분류 없이 저장 ]     │  ← 보조
 └─────────────────────────┘
```

**케이스 A — 프로젝트가 이미 있을 때 (반복 사용·두 번째 던지기~) · 같은 화면의 추천 모드**
```
 ┌─────────────────────────┐
 │  ✕                      │
 │  "로그인 화면 A/B 테스트 │
 │   해보면 어떨까"         │
 │─────────────────────────│
 │  AI 추천 · 어디에 담을까?│
 │  [ 🟦 결제개편    ‹유력›]│  ← 1초 탭이면 끝
 │  [ 🟩 온보딩리뉴얼     ]│
 │  [ 🟨 검색고도화       ]│
 │  ─────  또는  ─────     │
 │  [ + 새 프로젝트 ]      │
 │  [ 분류 없이 저장 ]     │
 └─────────────────────────┘
```
- **역할:** 자동(오배치)도 수동(마찰)도 아닌 반자동 분류. 있으면 AI 후보를 1초에 고르고, 없으면 이름을 직접 입력해 즉석 등록
- **담는 정보·요소:** 방금 던진 내용(고정) · AI 추천(기존 프로젝트 칩 ‹유력› 표시) · 새 프로젝트 이름 직접 입력 · 분류 없이 저장
- **주 행동:** [이 프로젝트로 담기] 또는 추천 칩 1탭 → ④  (전진 조건: 프로젝트 선택/생성 또는 '분류 없이 저장')
- **참고:** AI 매칭 정확도·후보 개수(3개 가정)·신뢰도 표시 방식은 구현 단계 튜닝

### ④ 홈 (결과 확인)
```
 ┌─────────────────────────┐
 │  톡캐치            ⚙   │
 │─────────────────────────│
 │  ✓ '로그인 개선'에 담았어요│  ← 확인 토스트 (이름은 직접 입력한 값)
 │─────────────────────────│
 │  📁 로그인 개선       1 │
 │   └ "로그인 화면 A/B     │
 │      테스트 해보면 어떨까"│
 │      · 방금              │
 │                         │
 │─────────────────────────│
 │  [  + 아이디어 던지기 ] │  ← 항상 하단, 누르면 ②로 (이번엔 ③이 추천 모드)
 └─────────────────────────┘
```
- **역할:** 방금 던진 게 어디 들어갔는지 눈으로 확인시켜 aha를 마무리. 플로우 2(프로젝트별 모아보기)의 첫 씨앗
- **담는 정보·요소:** 확인 토스트 · 프로젝트별 그룹(이름·개수) · 방금 메모 펼침 · 하단 고정 [+ 아이디어 던지기]
- **주 행동:** (플로우 종료) — 반복 캡처는 [+ 아이디어 던지기] → ②

**핵심 가치:** 던지는 순간 아무것도 안 물어보고(가벼움), 던진 직후 AI가 분류를 대신 좁혀준다(똑똑함). 이 두 박자를 절대 놓치지 않는다.

**참고:** 첫 캡처는 즉석 등록(케이스 B)으로 끝나고, 반자동 매칭(케이스 A)의 본격 경험은 두 번째 던지기부터 — 같은 ③ 화면이 프로젝트 보유 여부에 따라 모드를 바꾼다.

## 플로우 2 · 모아보고 키우기 — "회의 전에 모아보자"  [메인 기능: 프로젝트별 모아보기 · 선택 공유]

**목표 순간:** 회의 직전 "이 프로젝트 적어둔 거 모아보자" → 프로젝트를 열자 흩어진 줄 알았던 아이디어가 **한눈에 모여 있고**, 쓸 만한 걸 골라 **"공유" 한 번으로 팀 보드에 올림** (상태 변화: 흩어진 줄 앎 → 한눈에 모임 / 혼자 묵힘 → 팀과 함께 키움)

> **설계 노트:** 플로우 1을 여러 번 돌아 아이디어가 이미 쌓인 상태에서 출발한다. 메모 편집은 별도 상세 화면(③)에서, 공유는 "팀 보드에 올림"까지만 닫는다(팀 보드·코멘트 상세 화면은 v1 확장).

**단계 시퀀스**

| 단계 | 화면 | 기능 | 주 행동 (→ 전진) | 보조 |
|:--:|------|------|------------------|------|
| ① | 홈 (채워진 상태) | 프로젝트별 모아보기 | 프로젝트 탭 → ② | 🔍 검색 |
| ② | 프로젝트 상세 | 프로젝트별 모아보기 | 메모 카드 탭 → ③ | 이 프로젝트에 던지기 |
| ③ | 메모 상세·편집 | 메모 수정·삭제·재분류 | [팀에 공유하기] → ④ | 본문 수정 / 삭제 / 재분류 |
| ④ | 공유 | 선택 공유 & 코멘트 | [팀 보드에 올리기] → 완료 | 한마디 덧붙이기 |

**화면**

### ① 홈 (채워진 상태)
```
 ┌─────────────────────────┐
 │  톡캐치        🔍   ⚙  │
 │─────────────────────────│
 │  📁 결제개편          5 │
 │  📁 온보딩리뉴얼      3 │
 │  📁 검색고도화        2 │
 │  📁 로그인개선        1 │
 │─────────────────────────│
 │  [  + 아이디어 던지기 ] │
 └─────────────────────────┘
```
- **역할:** 회의 전 "이 프로젝트"를 바로 찾는 진입점. 프로젝트별 그룹 + 개수
- **담는 정보·요소:** 프로젝트 그룹(이름·메모 수, 최근 활동순) · 🔍검색 · 하단 고정 캡처 버튼
- **주 행동:** 프로젝트 탭 → ②

### ② 프로젝트 상세 (모아보기)
```
 ┌─────────────────────────┐
 │  ← 결제개편      🔍  ⋮  │
 │─────────────────────────│
 │ ┌─────────────────────┐ │
 │ │ PG사 수수료 비교     │ │
 │ │ · 2일 전      🔗공유됨│ │
 │ └─────────────────────┘ │
 │ ┌─────────────────────┐ │
 │ │ 결제 실패 리트라이   │ │
 │ │ · 어제               │ │
 │ └─────────────────────┘ │
 │ ┌─────────────────────┐ │
 │ │ 로그인 A/B 테스트... │ │
 │ │ · 방금               │ │
 │ └─────────────────────┘ │
 │─────────────────────────│
 │  [ + 이 프로젝트에 던지기]│
 └─────────────────────────┘
```
- **역할:** 한 프로젝트의 아이디어를 한눈에 모아 회의 전 점검 (목표 순간 1)
- **담는 정보·요소:** 메모 카드 리스트(내용 미리보기·시각·공유 배지, 최근순) · 🔍검색 · 이 프로젝트에 바로 던지기
- **주 행동:** 메모 카드 탭 → ③

### ③ 메모 상세 · 편집
```
 ┌─────────────────────────┐
 │  ←              ⋮ 수정/삭제│
 │─────────────────────────│
 │  로그인 화면 A/B 테스트   │
 │  해보면 어떨까            │
 │                         │
 │  📁 결제개편 ▾           │  ← 눌러서 재분류
 │  · 방금 · 개인           │
 │─────────────────────────│
 │  [   🔗 팀에 공유하기   ]│
 └─────────────────────────┘
```
- **역할:** 맥락이 증발한 메모를 다듬고(수정), 잘못 분류된 건 재분류, 필요 없으면 삭제. 공유 진입점
- **담는 정보·요소:** 본문(탭해 인라인 편집) · 프로젝트 재분류(▾) · 수정/삭제(⋮) · [팀에 공유하기] · 개인/공유 상태
- **주 행동:** [팀에 공유하기] → ④ (수정·삭제·재분류는 보조)
- *idea 확장의 AI 맥락 보강(한 줄 요약 제안)이 붙기 좋은 자리 — **P1**.*

### ④ 공유 (→ 완료)
```
 ┌─────────────────────────┐
 │  팀에 공유                │
 │─────────────────────────│
 │  "로그인 화면 A/B 테스트  │
 │   해보면 어떨까"          │
 │                         │
 │  → 결제개편 팀 보드        │
 │  ┌ 한마디 덧붙이기(선택) ┐ │
 │  │ ____________________ │ │
 │  └─────────────────────┘ │
 │─────────────────────────│
 │  [   팀 보드에 올리기   ]│
 └─────────────────────────┘
         ↓ 완료
   ✓ 팀 보드에 올렸어요
   팀원이 코멘트로 함께 키워가요
```
- **역할:** 개인 공간의 메모를 고른 것만 팀 보드로 올려 함께 발전 (목표 순간 2)
- **담는 정보·요소:** 공유할 메모 · 대상 팀 보드 · 한마디(선택) · [팀 보드에 올리기] · 완료 토스트
- **주 행동:** [팀 보드에 올리기] → 공유 완료 (종료)
- **로그인 연결:** 게스트 사용자는 이 "공유" 순간에 로그인 요구 — 플로우 1에서 미뤄둔 마찰을 여기서 닫는다.

**핵심 가치:** 흩어졌다고 느낀 아이디어가 프로젝트별로 다 모여 있다는 안도 + 개인에 안전하게 묵힌 것 중 "고른 것만" 팀으로 올리는 통제감. 이 둘을 지킨다.

**참고:** 팀 보드·코멘트 상세 화면, AI 맥락 보강은 v1 확장(P1). 공유 시 로그인 유도 UX는 구현 단계에서 구체화.
